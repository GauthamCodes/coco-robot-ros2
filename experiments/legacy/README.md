# Historical orchestration

These files have no current code consumers (repository search, 2026-10-02).
They are preserved for provenance; the canonical mission uses
`coco_mission/launch/mission.launch.py` and simulator backends.

- `overnight_chain.sh`: pre-fetch research orchestration with obsolete absolute
  workspace paths, broad process killing and in-place source edits. Execution
  is disabled. Git history retains its original contents.
- `train_curriculum.sh.next`: an unreferenced alternate curriculum script.
  It is retained as an experiment, not installed or used by mission launches.

The active curriculum tools remain at the repository root. No historical
measurements or simulator assets were removed.
